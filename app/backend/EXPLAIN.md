# Backend — Mock API (DentistAm)

Данный сервис представляет собой mock-реализацию REST API на FastAPI с фиксированными данными в памяти. Цель — продемонстрировать подход к организации взаимодействия между Backend и Frontend: структуру эндпоинтов, форматы ответов, пагинацию и обработку ошибок.

## Структура модулей

| Модуль | Эндпоинт | Описание |
|---|---|---|
| `employee` | `GET /api/v1/employees` | Список сотрудников клиники |
| `product` | `GET /api/v1/products` | Перечень предоставляемых услуг |
| `review` | `GET /api/v1/reviews` | Видеоотзывы пациентов |
| `application` | `POST /api/v1/applications` | Оформление заявки на приём |

Каждый модуль содержит:
- `schema.py` — Pydantic-модели запроса/ответа
- `data.py` — mock-данные (статическая таблица в памяти)
- `service.py` — бизнес-логика (фильтрация, пагинация)
- `resolver.py` — FastAPI-роутер с объявлением эндпоинтов

## TODO-маркеры

В коде расставлены `TODO`-комментарии, которые обозначают точки расширения при переводе в продовую реализацию:

- **Дополнительные поля моделей** — например, `education`, `experience` для сотрудников; `price`, `old_price` для услуг; `rate`, `text`, `created_at` для отзывов.
- **Взаимодействие с базой данных** — сервисы содержат заглушку, где должны располагаться `async`-методы работы с ORM (create, retrieve, update, destroy).
- **Обработка ошибок** — `not_found_exception` и другие заранее подготовленные исключения.
