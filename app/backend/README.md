# DentistAm — Backend

Mock REST API для фронтенд-приложения DentistAm. Реализовано на FastAPI с фиксированными данными в памяти.

## Стек

- **Python 3.14**
- **FastAPI** + **Uvicorn**
- **Pydantic v2** + **pydantic-settings**
- **uv** — менеджер пакетов и окружений
- **Docker** / **Docker Compose**

## Запуск

### Docker (рекомендовано)

```bash
cp .env.example .env          # скопировать конфиг
docker compose up --build     # собрать и запустить
```

API будет доступен на `http://localhost:${PORT}` (по умолчанию `:8080`).

### Локально

```bash
uv sync                                         # установить зависимости
uv run uvicorn src.main:app --reload            # запустить сервер
```

При локальном запуске убедитесь, что переменные из `.env` выставлены или корректны дефолты в `core/config.py`.

## Документация API

После запуска интерактивная документация доступна по адресам:

- **Swagger UI** — `http://localhost:${PORT}/docs`
- **ReDoc** — `http://localhost:${PORT}/redoc`

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/health` | Проверка доступности сервиса |
| `GET` | `/api/v1/employees` | Список сотрудников |
| `GET` | `/api/v1/products` | Список услуг |
| `GET` | `/api/v1/reviews` | Список отзывов |
| `POST` | `/api/v1/applications` | Создать заявку на приём |

Все `GET`-коллекции поддерживают пагинацию через query-параметры:

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `page` | `int` | `1` | Номер страницы |
| `per_page` | `int` | `10` | Элементов на странице (макс. 100) |

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DEBUG` | `False` | Режим отладки |
| `HOST` | `localhost` | Хост для локального запуска |
| `PORT` | `8000` | Порт сервера |
| `TITLE` | `DentistAm API` | Название в документации |
| `ALLOWED_HOSTS` | `["*"]` | Разрешённые CORS-источники (JSON-массив) |
| `STATIC_PATH` | `static` | Путь к папке со статикой |

## Структура проекта

```
src/
├── main.py              # Точка входа: регистрация роутеров, middleware, статика
├── core/
│   ├── config.py        # Конфигурация через pydantic-settings
│   └── pagination.py    # Универсальная пагинация
└── modules/
    ├── employee/        # Сотрудники клиники
    ├── product/         # Услуги клиники
    ├── review/          # Отзывы пациентов
    └── application/     # Заявки на приём
```
