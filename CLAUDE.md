# DentistAm — Правила проекта

Одностраничный лендинг стоматологической клиники. Монорепо: `app/backend/` (FastAPI) + `app/frontend/` (Next.js 16).

## Структура

```
app/
├── backend/   FastAPI + SQLAlchemy
└── frontend/  Next.js 16 App Router — основная рабочая область
```

Детальные правила для frontend — см. `app/frontend/CLAUDE.md`.
